# GPT Image 2 Guidance

Use Codex built-in image generation for normal conceptual-figure creation and editing.

For model-specific CLI/API work, GPT Image 2 is the default modern image model. Useful landscape sizes include `1536x1024`, `2048x1152`, and `3840x2160`; portrait equivalents are also available. Use higher quality for dense text, diagrams, and final paper figures.

Do not set edit input fidelity for GPT Image 2; image inputs are already handled with high fidelity. Do not assume native transparent-background output is available with GPT Image 2.

Model-specific details can change, so verify current OpenAI image-generation documentation before relying on exact API limits or fallback behavior.
