# Mathematical Modeling Figures

Mathematical modeling is a first-class use case.

A strong framework figure usually follows this chain:

`problem and data -> assumptions / preprocessing -> model construction -> parameter estimation or forecasting -> optimization / solution -> validation -> sensitivity / robustness -> final decision`

Keep dependencies between submodels explicit. Preserve model names, variables, symbols, units, and constraints from the paper. Do not invent formulas or results.

Use image mode for conceptual model-framework diagrams, plot mode for exact result figures, and mixed mode when a framework figure includes both.
