# Plot Mode

Use plot mode when numeric values, axes, scales, or uncertainty must stay exact.

Typical figures: benchmark, ablation, trend, scatter, heatmap, and sensitivity plots.

Render from supplied data with local plotting tools. Preserve values, units, ordering, axis meaning, legends, and uncertainty notation. Prefer vector export when useful. Check clipping and readability before delivery.

Do not redraw exact plots with an image-generation model.
