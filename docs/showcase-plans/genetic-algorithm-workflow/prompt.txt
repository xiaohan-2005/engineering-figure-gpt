创建一张论文级、白底、横向的遗传算法（Genetic Algorithm, GA）流程图，重点表现迭代循环、终止判断和最终输出。图必须像科研论文中的算法流程，而不是卡通海报或商业信息图。

主流程必须严格保持：
参数与约束 → 初始化种群 → 适应度评价 → 选择 → 交叉 → 变异 → 新一代种群 → 终止条件？

终止判断必须使用清晰的菱形决策节点：
- “否”分支返回下一轮“适应度评价”，形成一条容易追踪的迭代回路；
- “是”分支离开循环，进入“输出最优候选”。

必须正确显示并保留以下中文标签：
参数与约束、初始化种群、适应度评价、选择、交叉、变异、新一代种群、终止条件？、否、是、输出最优候选。

可以在标题中使用“遗传算法（Genetic Algorithm, GA）”。如果加入精英保留，仅允许作为视觉上次要、通用的小分支，不得暗示所有 GA 都必须使用精英策略。

严谨性要求：
- “选择”必须位于“交叉”和“变异”之前；
- 不得虚构种群规模、交叉概率、变异概率、最大迭代次数、适应度数值、收敛曲线或最优目标值；
- 不得添加背景中没有的编码方式、选择算子名称、交叉算子名称、变异算子名称或约束处理方法；
- 不生成公式或伪代码段；
- 不把终止判断画成线性普通模块，必须让“是/否”逻辑一眼可辨。

视觉要求：
- 白色背景、横向构图；
- 低饱和蓝、青绿、中性灰为主，终止判断可以使用非常克制的浅强调色；
- 统一圆角流程模块，菱形终止判断，细而明确的箭头；
- 循环回箭头绕开主要标签，避免交叉线和视觉混乱；
- 中文字体清晰、字号一致、模块间距均衡；
- 可以使用极简的小型遗传/染色体抽象符号，但符号不能代替文字；
- 不使用照片、3D 物体、霓虹光效、Logo、水印、虚构引用或大面积装饰渐变。

最终图应让读者在几秒内理解 GA 的“初始化—评价—遗传操作—新一代—终止判断—循环/输出”控制逻辑，并适合作为算法方法章节中的正式流程图。
