# Figure Brief — Multi-source Fusion Graphical Abstract

- **slug:** `multisource-fusion-graphical-abstract`
- **figure_goal:** demonstrate a polished graphical abstract with semantic composition rather than exact plotting.
- **paper_claim:** heterogeneous data can be transformed into aligned representations, fused, and passed to a downstream prediction/decision stage; no performance improvement is claimed.
- **figure_type:** graphical abstract.
- **mode:** image.
- **language:** English.
- **orientation:** landscape, compact four-stage story.

## Intended structure

```text
Multi-source Data
  - Structured Data
  - Images
  - Text
        ↓
Feature Extraction & Alignment
        ↓
Fusion Module
        ↓
Prediction / Decision
```

A small lower strip may show `Robustness`, `Interpretability`, and `Efficiency` as evaluation considerations, but not as achieved results.

## Must-keep labels

- Multi-source Data
- Structured Data
- Images
- Text
- Feature Extraction & Alignment
- Fusion Module
- Prediction / Decision
- Robustness
- Interpretability
- Efficiency

## Style constraints

- graphical-abstract quality suitable for an AI/data-science paper;
- white background with clear stage separation;
- restrained blue/teal/neutral palette plus one small accent color;
- simple semantic icons for table/image/text inputs are allowed;
- the fusion stage should look like integration of representations, not a decorative network with fake equations;
- keep text minimal.

## Verification targets

- three input modalities remain visually distinct before alignment/fusion;
- feature extraction/alignment precedes fusion;
- prediction/decision comes after fusion;
- robustness/interpretability/efficiency are presented as considerations, not guaranteed outcomes;
- no accuracy gain, dataset name, sample count, architecture depth, loss function, or unsupported module is invented.
