# Engineering Figure GPT

A Codex-native skill for publication-style research figures in engineering, computer science, AI, data science, and mathematical modeling.

- `image` mode uses Codex built-in GPT image generation for conceptual figures and edits.
- `plot` mode keeps exact quantitative figures local.
- `mixed` mode combines exact local quantitative panels with GPT-generated conceptual panels.

The skill prioritizes scientific fidelity, concise labels, clear reading order, publication readability, and faithful Chinese/English technical terminology.
